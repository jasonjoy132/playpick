첨부한 CSV는 게임 목록이야. (id, 제목, 원제, 업체, 플랫폼, 장르, 연도, 출처, 스토어 주소)
출처가 '게임물관리위원회(한국)'인 게임은 대부분 작은 국내 모바일·온라인 게임이야.
각 게임이 **지금** 처음 시작할 때 **무료인지 유료인지** 알려 줘.

- **free(무료)**: 돈을 내지 않고 내려받아 처음부터 플레이할 수 있음. 게임 안 결제(인앱 결제)·유료 DLC가 있어도 무료야.
- **paid(유료)**: 게임을 사야 하거나, 구독(월정액)을 해야 플레이할 수 있음.
- 예전에는 유료였다가 무료로 바뀐 게임(또는 반대)은 **지금** 상태로 답해 줘.
- 옛날 콘솔 게임처럼 지금 파는 곳이 없어도, 원래 사서 하는 게임이었으면 paid.

**아주 중요한 규칙**
1. `known`은 **이 게임을 정확히 찾았고 무료·유료를 확인했을 때만** `true`.
   - 웹 검색을 했다면 스토어 페이지(App Store·Google Play·Steam·공식 사이트)에서 가격이나 '무료' 표시를 확인해 줘.
2. 확인하지 못했으면 `known`은 `false`, `free`는 **비워 둬**.
3. **제목·업체·장르만 보고 짐작하지 마.** (예: "모바일 게임이니까 무료"처럼 짐작 금지)
4. `evidence`에는 확인한 곳 주소나 짧은 근거를 적어 줘. (없으면 비워도 돼)
5. CSV의 **모든 id에 한 줄씩**, 같은 id를 그대로 써서 답해 줘.

**답 형식 (CSV, 머리글 포함)**
```
id,known,free,evidence
1,true,paid,https://store.steampowered.com/app/... 구매 필요
2,false,,
3,true,free,https://play.google.com/store/apps/details?id=... 무료(인앱 결제 있음)
```
