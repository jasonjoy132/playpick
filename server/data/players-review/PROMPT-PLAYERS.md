# 외부 AI에게 줄 질문 (게관위 게임 추천 인원)

`players-part1.csv`, `players-part2.csv` … 를 **하나씩** 첨부하거나 붙여 넣고, 아래 글을 함께 보내세요.
**웹 검색이 되는 AI(검색 켜기)**를 쓰면 훨씬 정확해요. 받은 답은 `result-part1.csv`처럼 저장해서 알려 주세요.

---

첨부한 CSV는 한국 게임물관리위원회(GRAC)에서 등급분류를 받은 게임 목록이야. (id, 제목, 업체, 플랫폼, 장르, 등급분류일, App Store 주소)
대부분 작은 국내 모바일·온라인 게임이야. 각 게임의 **추천 플레이 인원**을 알려 줘.

**추천 플레이 인원**이란: 친구들이 **한 팀·한 파티로 같이** 하는 인원이야. 한 판에 들어오는 전체 인원이 아니야.
- 예: 배틀그라운드 → 1~4 (솔로·듀오·스쿼드), 리그 오브 레전드 → 1~5, 마인크래프트 → 1~8, 혼자만 하는 게임 → 1~1
- min: 같이 하는 가장 적은 인원 (혼자 할 수 있으면 1)

**아주 중요한 규칙**
1. `known`은 **이 게임을 정확히 찾았고 어떻게 플레이하는지 확인했을 때만** `true`.
   - 웹 검색을 했다면 스토어 페이지·공식 사이트·리뷰 등에서 **같이 하기(멀티·협동·대전) 기능이 있는지** 확인해 줘.
2. 확인하지 못했으면 `known`은 `false`, `min`·`max`는 **비워 둬**.
3. **제목·업체·장르만 보고 짐작하지 마.** (예: "퍼즐이니까 1~1"처럼 짐작 금지)
4. `evidence`에는 확인한 곳 주소나 짧은 근거를 적어 줘. (없으면 비워도 돼)
5. CSV의 **모든 id에 한 줄씩**, 같은 id를 그대로 써서 답해 줘.

**답 형식 (CSV, 머리글 포함)**
```
id,known,min,max,evidence
1,true,1,4,https://apps.apple.com/... 4인 협동 모드 있음
2,false,,,
3,true,1,1,https://... 싱글 플레이만 지원
```
